建站经历：用 AI 辅助搭建个人网站

发表于2026-09-28|更新于2026-09-28
|浏览量:

这是我的第一篇blog，记录的是我使用Deepsseek辅助建立网站的过程，希望能帮助同样有建立属于自己网站的小伙伴

Q：我现在想从0搭建一个属于自己的网站，可以放个人简历，一些项目经历和一些学习笔记、保研经历分享，接下来你来一步一步辅助我

A：

可以，我们按 “先上线，再美化，再扩展” 的节奏来。你不需要先学完整前端，也不需要买服务器。第一版目标很简单：有一个能访问的网址，包含首页、简历、项目、学习笔记、保研分享。

整体路线

我们会分这几步：

  1. 确认需求与选型：确定用什么工具、部署在哪里
  2. 安装环境：Git、Node.js 等
  3. 创建网站项目：本地跑起来
  4. 写内容：简历、项目、笔记、保研分享
  5. 配置主题：导航、标签、搜索、深色模式
  6. 部署上线：GitHub Pages / Vercel / Cloudflare Pages
  7. 绑定域名与优化：HTTPS、SEO、统计、备份
  8. 持续更新：以后像写 Markdown 一样发文章

我建议的默认方案

如果你没有特别偏好，我建议默认走这条：

  • 建站框架：Hexo
  • 主题：Butterfly 或 Stellar
  • 写作方式：Markdown
  • 托管：GitHub Pages 或 Vercel / Cloudflare Pages
  • 成本：0 元起步，域名可选
  • 优点：中文教程多，适合博客、笔记、经验分享，也能做简历页和项目页
  • 缺点：主题配置项较多，但跟着做没问题

如果你以后更想自己改前端，可以换 Astro；如果只想文档风，可以用 Hugo + Stack。但第一版我建议先用 Hexo。

现在进行第 1 步：确认你的情况

请你直接按下面格式回复我，例如：

Windows / 零基础 / 有 GitHub / 只想免费 / 博客型 / 需要搜索和深色 / 中文

你需要回答这 7 个问题：

  1. 你的电脑系统：Windows、macOS 还是 Linux？
  2. 你的编程基础：完全零基础、会一点 HTML/CSS/JS、还是会其他语言？
  3. 你有没有 GitHub 账号？
  4. 预算：只想免费，还是可以花几十元买域名？
  5. 网站风格偏好：极简个人主页、博客型、作品集型、文档型？
  6. 必须功能：搜索、深色模式、标签分类、评论、RSS、统计，哪些需要？
  7. 内容语言：中文为主，还是中英双语？

如果你不想逐条选，也可以直接回复：

按默认来

收到后，我下一步会带你：安装 Git 和 Node.js，并创建你的第一个本地网站项目，具体到每一步命令。

Q：Windows / 零基础 / 有 GitHub / 只想免费 / 博客型 / 需要搜索和深色 / 中文，后续我还想在网站中接入AI，可以回答一些我笔记中的问题，比如我现在在写ROS学习笔记

A：

好的，情况很清晰了。我们用 Hexo + Butterfly 主题 + GitHub Pages 这套方案，完全可以满足你“免费、博客型、中文、有搜索和深色模式”的需求。关于你提到的 ROS 学习笔记 AI 问答，这完全可行，而且有现成的、同样免费的方案可以接入，我们把它作为第二阶段的目标。

下面是为你定制的第一步：在 Windows 上从零把网站跑起来，并部署到网上。

📦 第一步：安装两件“基础设施”

你需要先安装两个软件，它们是整个网站的地基。

  1. Node.js：Hexo 的运行环境。去官网下载 LTS（长期支持）版本，下载后双击安装，一路点“Next”即可，它会自动配置好环境变量。
  2. Git：用于把代码推送到 GitHub。同样去官网下载 Windows 版本，安装时也一路默认“Next”就行。

安装完成后，在电脑上随便找个地方（比如桌面）右键，选择 “Git Bash Here”，打开一个黑色命令行窗口，输入下面两行命令来验证是否成功：

bash

node -v
git –version

如果分别显示了版本号（如 v24.x.x 和 git version 2.x.x），就说明安装成功了。

🏗️ 第二步：初始化你的博客项目

还是在刚才的 Git Bash 窗口里，依次执行以下命令。假设你想把博客放在 D:\blog 目录下。

bash

1. 安装 Hexo 命令行工具

npm install -g hexo-cli

2. 进入 D 盘（如果你的博客想放在其他盘，把 D: 换成对应盘符）

cd /d/blog

3. 初始化一个名为 myblog 的博客项目

hexo init myblog

4. 进入项目文件夹

cd myblog

5. 安装项目依赖

npm install

执行完毕后，D:\blog\myblog 文件夹里就是你的博客源代码了。

🦋 第三步：换上功能齐全的 Butterfly 主题

Hexo 默认的主题比较简陋，我们直接换上功能强大的 Butterfly 主题，它原生就支持本地搜索和深色模式。

在 myblog 目录下，继续执行：

bash

1. 通过 npm 安装 Butterfly 主题及必要的渲染器

npm i hexo-theme-butterfly hexo-renderer-pug hexo-renderer-stylus

安装完成后，需要修改配置文件来启用它。

  1. 修改站点主配置：用记事本或 VS Code 打开 myblog 文件夹下的 _config.yml 文件，找到 theme: 这一行，把它改成：yaml
    theme: butterfly
    同时，建议把 language: 改成 zh-CN，这样网站界面就是中文了。
  2. 生成主题配置文件：Butterfly 主题的个性化设置都在一个单独的文件里。在 myblog 目录下，右键打开 Git Bash，执行下面这行命令来生成它：bash
    cp node_modules/hexo-theme-butterfly/_config.yml _config.butterfly.yml
    现在，你的 myblog 目录下就会多出一个 _config.butterfly.yml 文件，所有的主题设置都在这里改。

⚙️ 第四步：配置搜索与深色模式

打开 _config.butterfly.yml，我们来开启你最需要的两个功能。

  1. 开启本地搜索：
    找到 local_search 部分（可以用 Ctrl+F 搜索），把它改成：yaml
    local_search:  enable: true
    然后，还需要在 myblog 目录下安装一个搜索索引生成插件：bash
    npm install hexo-generator-search –save
    最后，打开 myblog 根目录的 _config.yml 文件，在文件末尾添加以下配置，告诉 Hexo 生成搜索文件：yaml
    search:  path: search.xml  field: post  content: true
  2. 开启深色模式：
    在 _config.butterfly.yml 中找到 darkmode 部分，设置为：yaml
    darkmode:  enable: true  button: true  # 会在页面右下角显示一个手动切换的按钮
    这样，访问者就可以根据喜好切换深色/浅色模式了。

🚀 第五步：本地预览效果

所有配置完成后，在 myblog 目录下执行以下命令，在本地启动预览服务器：

bash

hexo clean && hexo g && hexo s

然后用浏览器打开 http://localhost:4000，你应该就能看到一个带有 Butterfly 主题、支持搜索和深色模式的博客了。可以按 Ctrl+C 停止本地服务器。

☁️ 第六步：部署到 GitHub Pages（让它上线）

  1. 在 GitHub 创建仓库：
    登录你的 GitHub，新建一个仓库。仓库名必须严格按照格式：你的用户名.github.io（例如 zhangsan.github.io）。创建时选择 Public。
  2. 安装部署插件：
    在 myblog 目录下执行：bash
    npm install hexo-deployer-git –save
  3. 配置部署地址：
    打开 myblog 根目录的 _config.yml，拉到最底部，修改 deploy 部分：yaml
    deploy:  type: git  repo: https://github.com/你的用户名/你的用户名.github.io.git  branch: main
    请把 你的用户名 替换成你实际的 GitHub 用户名。
  4. 一键部署上线：
    在 myblog 目录下执行：bash
    hexo clean && hexo g && hexo d
    第一次执行 hexo d 时，可能会弹出窗口让你登录 GitHub 授权。授权后，等待命令执行完毕。稍等一两分钟，访问 https://你的用户名.github.io，你的网站就正式上线了！

🤖 关于未来的 AI 问答

你希望用 AI 回答笔记中的问题，这个目标可以通过 RAG（检索增强生成） 技术来实现，简单说就是让 AI 先“学习”你的笔记，再基于笔记内容回答。

目前已经有多种为 Hexo 博客设计的免费方案，例如 hexo-blog-rag-mcp、hexo-plugin-postchat-liushen 和 ChatHexo。它们通常的运作方式是：将你的文章内容转换成向量存入数据库，用户提问时，系统先检索相关笔记片段，再交由 AI 模型生成回答。

所以，完全不用担心。我们先把网站基础打好，等你熟悉了 Hexo 的写作和更新流程，有了几篇 ROS 笔记之后，我们再选择一个合适的 RAG 方案来集成 AI 问答。

Q：第二步：初始化你的博客项目；我想把项目放在F:\blog

A：

因为你现在还在 C:\Users\水容> 目录下，Windows 的命令行不能直接跨盘符跳转（直接输 cd F:\blog 是无效的）。你需要先切换到 F 盘，再进入目录。

请在你当前的命令行窗口里，依次执行下面的命令：

第一步：切换到 F 盘并创建文件夹

cmd

1. 切换到 F 盘

F:

2. 在 F 盘根目录创建一个名为 blog 的文件夹

mkdir blog

3. 进入这个文件夹

cd blog

执行完这三步后，你的命令行路径应该会变成 F:\blog>。

第二步：初始化项目

接下来继续执行 Hexo 的初始化命令（如果你刚刚已经在 C 盘安装过 hexo-cli，就不用再装一次了，直接执行第 2 条开始）：

cmd

（可选）如果你还没安装过 Hexo 命令行工具，执行这一条

npm install -g hexo-cli

1. 初始化一个名为 myblog 的项目

cd myblog

⚠️ 避坑提示：

cmd

npm install -g cnpm –registry=https://registry.npmmirror.com
cnpm install

以后的命令中，如果遇到 npm 相关的卡顿，都可以用 cnpm 代替 npm 来加速。

Q：访问页面是这样的，这是正确的吗，下一步怎么做

A：

完全正确！ 恭喜你，你已经成功把网站跑在本地了。这个页面就是 Hexo 默认的初始主题界面，说明你的环境、项目初始化、依赖安装都没有任何问题。

现在，请先在当前的命令行窗口里按 Ctrl + C 停止当前的本地服务器（否则后面安装新东西会冲突）。

接下来我们进行第三步：换上功能齐全的 Butterfly 主题。请在你当前的 F:\blog\myblog 目录下，依次执行以下操作：

第一步：安装主题和必要插件

在命令行里执行：

cmd

npm install hexo-theme-butterfly hexo-renderer-pug hexo-renderer-stylus –save

（如果速度慢，可以按 Ctrl+C 终止，然后执行 cnpm install hexo-theme-butterfly hexo-renderer-pug hexo-renderer-stylus –save）

第二步：修改站点主配置文件（_config.yml）

  1. 打开电脑的文件资源管理器，进入 F:\blog\myblog 文件夹。
  2. 找到 _config.yml 文件，右键 -> 打开方式 -> 记事本（或者用 VS Code 打开）。
  3. 找到 theme: landscape 这一行，把它改成：yaml
    theme: butterfly
  4. 找到 language: en 这一行，把它改成：yaml
    language: zh-CN
  5. 保存并关闭这个文件。

第三步：生成主题专属配置文件

我们需要把主题的配置模板复制到项目根目录，方便你以后修改。回到命令行，执行：

cmd

copy node_modules\hexo-theme-butterfly_config.yml _config.butterfly.yml

执行完后，你的 F:\blog\myblog 文件夹里会多出一个 _config.butterfly.yml 文件。

第四步：开启搜索和深色模式

  1. 用记事本打开刚才生成的 _config.butterfly.yml 文件。
  2. 开启搜索：按 Ctrl+F 搜 local_search，把 enable: false 改成 enable: true。
  3. 开启深色模式：搜 darkmode，把 enable: false 改成 enable: true，如果看到 button: false，也改成 button: true。
  4. 保存并关闭。

第五步：安装搜索索引生成插件

回到命令行，安装搜索所需的插件，并配置生成规则：

cmd

npm install hexo-generator-search –save

安装完成后，再次打开 F:\blog\myblog 下的 _config.yml 文件（主配置文件），在文件最末尾添加以下内容，保存：

yaml

search:  path: search.xml  field: post  content: true

第六步：重新预览

所有配置完成后，在命令行执行：

cmd

hexo clean && hexo g && hexo s

然后刷新浏览器 http://localhost:4000，你应该就能看到全新的 Butterfly 主题了！右下角会有深色模式切换按钮，顶部导航栏也会多出搜索功能。

⚠️ 避坑提示：

  • 修改 .yml 文件时，冒号后面一定要有一个空格（例如 theme: butterfly），这是 YAML 格式的硬性要求，缩进也要对齐。
  • 如果刷新后页面样式错乱，或者打不开，大概率是配置文件的缩进或空格写错了。可以截图发我帮你排查。

Q：初步创建我已经完成了，你能访问我的网站吗，来指出我下一步怎么做

A：

首先，我无法直接访问你的网站，因为你现在运行的是本地预览环境（http://localhost:4000），这个地址只存在于你的电脑上，外网无法访问。不过你现在可以在自己电脑的浏览器里打开看看，确认一下右上角的搜索图标和右下角的深色模式按钮是否出现了。

如果你本地看着一切正常，接下来我们就进行第六步：把网站部署到 GitHub Pages，让它真正上线，这样我就能访问了！

请按照以下步骤操作：

第一步：在 GitHub 上创建一个仓库

登录你的 GitHub。

点击右上角的 + 号，选择 New repository。

仓库名（Repository name）必须严格按照这个格式：你的GitHub用户名.github.io（例如你的用户名是 zhangsan，就填 zhangsan.github.io）。

下面的选项保持默认（Public），千万不要勾选 Add a README file、.gitignore 等任何文件。

点击 Create repository。

第二步：安装部署插件

回到你的命令行窗口（F:\blog\my-first-blog>），执行：

cmd

npm install hexo-deployer-git –save

第三步：修改主配置文件

打开 F:\blog\my-first-blog_config.yml（注意是主配置文件）。

拉到文件最底部，找到 deploy: 部分，修改成如下格式（注意缩进和冒号后的空格）：

yaml

deploy:

  type: git

  repo: https://github.com/你的用户名/你的用户名.github.io.git

  branch: main

⚠️ 重要：把上面的 你的用户名 替换成你真实的 GitHub 用户名（共两处，前面是网址，后面是仓库名）。比如：

repo: https://github.com/zhangsan/zhangsan.github.io.git

保存文件。

第四步：一键部署上线

回到命令行，执行：

cmd

hexo clean && hexo g && hexo d

执行 hexo d 时，可能会弹出一个 GitHub 的登录授权窗口，根据提示登录授权即可。授权成功后，等待命令行跑完。

如果最后没有出现红色的 ERROR，说明部署成功！

稍等 1~2 分钟，然后在浏览器访问：https://你的用户名.github.io，如果能看到你的网站，就说明正式上线了！
